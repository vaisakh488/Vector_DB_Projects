# 📊 Vector Space Visualization

This project visualizes text embeddings in 2D space using dimensionality reduction techniques.

## 🧠 Features

* Embedding generation using Sentence Transformers
* Dimensionality reduction (PCA, t-SNE, UMAP)
* Query visualization in vector space

## ▶️ Run

```bash
pip install -r requirements.txt
python app.py
```

## 🎯 Goal

Understand how semantic similarity works by visualizing vectors.
