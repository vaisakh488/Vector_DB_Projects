# 🚀 Vector DB Projects Lab

A hands-on collection of small projects exploring **Vector Databases, Embeddings, and Retrieval-Augmented Generation (RAG)**.

This repository is my learning space to experiment with different tools, architectures, and real-world AI patterns using Python, Docker, and modern ML frameworks.

---

## 🧠 What This Repo Covers

* 🔍 Semantic Search using embeddings
* 🧩 Vector Databases (FAISS, Qdrant, etc.)
* 🤖 RAG (Retrieval-Augmented Generation) systems
* 📦 Dockerized AI applications
* ⚙️ CI/CD for AI pipelines
* 📊 Model evaluation & experimentation

## ▶️ Getting Started

### 1. Clone the repository

```
git clone https://github.com/vaisakh488/Vector_DB_Projects.git
cd Vector_DB_Projects
```

---

### 2. Create a virtual environment

```
python -m venv .venv
source .venv/bin/activate   # Linux / Mac
.venv\Scripts\activate      # Windows
```
